## 摘要页眉变体

论文中存在两种页眉文字：
- 变体A：`河南科技大学毕业设计说明书（论文）`
- 变体B：`河南科技大学本科毕业设计（论文）`

两种均被接受。

## 目录编号格式

### 论文1：方案A（无 § 符号）
```
第1章 绪 论
1.1 研究背景及意义
1.2 国内外研究现状
1.3 研究方法与内容
第2章 需求分析
2.1 功能需求
2.2 非功能需求
2.3 可行性分析
2.3.1 社会可行性
2.3.2 技术可行性
```

### 论文2：方案B（使用 § 符号）
```
第 1 章 绪论
§1.1 课题背景
§1.2 研究意义
§1.3 研究内容
第 2 章 系统需求分析
§2.1 系统目标与需求分析
§2.1.1 系统目标
§2.1.2 系统的功能需求
```

### 论文3：方案A + 多级编号
```
第1章 绪 论
1.1 研发背景及意义
1.2 国内外研发现状
1.3 研发方法与内容
1.4 本文安排
第2章 可行性分析和需求分析
2.1 可行性分析
2.1.1 法律可行性
2.1.2 技术可行性
```

## 图表编号样本

### 图编号
- `图2.1 用例图`
- `图 3-1 救助信息申请流程图`
- `图 3.2 ER图`
- `图2-3 第二层用例图-员工管理`

注意：存在两种格式 `图X.Y` 和 `图X-Y`，推荐统一使用 `图X-Y`。

### 表编号
- `表3-1 用户表`
- `表5-3 预测服务模块`
- `表 7-3 添加数据测试用例`

## 总结与展望 / 结论格式

### 变体1：总结与展望
```
总结与展望

本系统作为一个...[总结内容]

在未来展望方面，本系统存在着一些不足以待发展迭代...[展望内容]
```

### 变体2：结论
```
结论

本次设计标志着...[总结]

尽管系统在试点中展现出了显著成效，但仍存在...[不足与展望]
```

### 变体3：结论（简洁）
```
结论

本系统设计并实现了...[总结]

系统在实现过程中...[过程回顾]

未来可在现有基础上，持续优化与扩展...[展望]
```
