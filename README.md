# HAUST-CS-Paper-Skill

河南科技大学本科毕业设计（论文）完整生成系统。

## 简介

本工具能够基于用户的毕业设计项目仓库，自动分析项目内容、研究相关技术背景、生成图表，最终输出一份内容充实、格式合规的完整 Word 论文文档。

## 功能特性

- **项目分析**：自动扫描项目代码，提取技术栈、功能模块、数据库结构等信息
- **网络研究**：搜索相关技术的国内外研究现状，生成 GB/T 7714 格式的参考文献
- **图表生成**：使用 Mermaid CLI 自动生成系统架构图、ER图、流程图等
- **文档生成**：使用 python-docx 生成符合河科大格式规范的 Word 论文，包括：
  - 封面、声明、中英文摘要、目录
  - 正文（自动上标引用、三线表、图片插入）
  - 参考文献、致谢

## 目录结构

```
henan-univ-thesis/
├── SKILL.md          # 论文格式规范与生成工作流定义
├── evals/            # 评估测试
├── references/       # 参考资料与格式样本
└── scripts/          # 脚本工具
```

## 使用方式

通过 Claude Code 加载本 skill，提供毕业设计项目仓库路径即可自动生成完整论文。
